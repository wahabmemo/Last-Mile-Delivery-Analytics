# Last-Mile-Delivery-Analytics

A Data-Driven Analysis of Last-Mile Parcel Delivery Performance and Operational Efficiency.

## Project Overview

This project focuses on analysing last-mile parcel delivery
performance using data analytics techniques.

## Problem Statement

Last-mile parcel delivery operations face challenges such as
delivery delays, unsuccessful delivery attempts and inefficient
delivery routes. These challenges can increase operational costs
and negatively affect customer satisfaction. Understanding
delivery performance and operational inefficiencies is important
for logistics companies.

## Project Objectives

- Analyse parcel delivery performance.
- Identify unsuccessful delivery attempts.
- Examine delivery time and route efficiency.
- Analyse operational performance trends.
- Develop an interactive analytics dashboard.

## Tools and Technologies

- Python
- SQL
- Pandas and NumPy
- Power BI
- Jupyter Notebook
- GitHub

## Dataset

Proposed dataset: Amazon Last Mile Routing Research Dataset.
